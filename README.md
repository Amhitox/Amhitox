## 🔬 What I'm building

Currently spearheading a **production-grade Moroccan Darija conversational voice AI** at [FINASHORE](https://finashore.com) — an end-to-end TTS/ASR pipeline that speaks the dialect of 40 million people. I benchmark state-of-the-art speech models (XTTS v2, Spark-TTS, Whisper), fine-tune LLMs for contextual Darija understanding, and build the dataset infrastructure from scratch.

On the engineering side, I build scalable full-stack systems — microservices on AWS, real-time backends with NestJS/Firebase, and polished frontends with Next.js & Angular.
