## 🧠 What I'm Building

> **Conversational voice AI for Moroccan Darija** — one of the most linguistically rich and underrepresented languages in the AI space. End-to-end: data scraping → model fine-tuning → real-time TTS/ASR pipelines → deployed voice agents.

I work across the full stack. On the AI side: XTTS v2, Spark-TTS, Whisper, PyTorch, HuggingFace. On the product side: Spring Boot microservices, Next.js frontends, NestJS APIs, Docker, AWS. I care about shipping things that actually work in production — not just demos.
