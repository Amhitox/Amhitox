## 🧠 About Me

- 🇲🇦 Based in **Casablanca, Morocco**
- 🔬 Building **voice AI for Moroccan Darija** — TTS, ASR, LLMs end-to-end
- ⚡ Full-stack engineer — Spring Boot · Next.js · NestJS · Laravel · FastAPI
- 🎯 Focused on rare, high-impact NLP for underrepresented languages
- 📦 I ship production-ready systems — not just demo projects
- 💬 Ask me about Darija speech models, fine-tuning, or microservices

## 🎯 Current Focus

```text
🔊 Conversational Voice AI for Moroccan Darija
   ├── 📊 Data pipeline: custom scrapers for Darija audio & text
   ├── 🧠 Fine-tuning: XTTS v2 + Spark-TTS + Whisper for Darija
   ├── ⚡ Real-time: TTS/ASR pipelines via pipecat framework
   └── 🚀 Goal: make Moroccan Arabic a first-class AI language
```

> One of the only open-source pipelines for Darija ASR/TTS in existence.
